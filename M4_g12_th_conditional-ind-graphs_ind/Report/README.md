# Report, M4

`M4_g12_th_conditional-ind-graphs_ind_Report.pdf` is the final report (16 pages, same story as the talk: Rhino basics and paper results, the gap, our idea / why logical / why it matters / plan / expectations, then the full method and a first test; 20 sections as in the course structure: Title, Abstract, Introduction, Problem Formulation, Background, Related Work, SOTA Positioning, Graphical Representation, Learning Method, Inference Method, Experimental Setup, Baselines, KPIs, Results, Statistical Analysis, Discussion, Limitations, Conclusion, References, Appendix).

## Format

The layout follows the style of an ICLR paper, as in the base paper (Rhino, ICLR 2023): thick rule above a small-caps title, 5.5 inch Times text, small-caps section heads, centred abstract, booktabs tables without vertical rules, author-year citations and an alphabetical reference list.
The official ICLR style file is not used (it is not part of a standard LaTeX install and nothing was downloaded). The page geometry and headings were set by hand in `Code/src/latex_lib.py`.
The running header names the course milestone. It does not claim any conference submission.

## Files

- `latex/M4_g12_th_conditional-ind-graphs_ind_Report.tex` is the source. `latex/figures/` holds the three figures it includes.
- The tex file is generated by `Code/src/build_report.py`, which reads every number from `Results/tables`. To change text, edit `build_report.py` and run it, or edit the tex directly and run `pdflatex` twice in `latex/`.
