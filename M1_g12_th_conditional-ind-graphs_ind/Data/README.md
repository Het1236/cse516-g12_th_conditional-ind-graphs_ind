# Data

No dataset has been finalized yet. This milestone (M1) is a proposal and scoping stage.

## Planned data

- Primary: synthetic Gaussian graphical model data, generated as Erdos-Renyi random sparse
  graphs, following the same protocol used in the uGLAD paper. This is generated directly by
  code, not downloaded, so no external dataset link is needed for it.
- Secondary (optional): a non-Gaussian gene regulatory network benchmark using the SERGIO
  simulator, the same secondary check used in the uGLAD paper.
